# Hi, I'm Lucy 👋

I'm a 3rd-year student at the University of Toronto Scarborough, studying **New Media** with minors in **Statistics** and **Economics**. I started in Computer and Mathematical Sciences, then switched to design because I got more curious about the people using my code than the code itself.

These days I design in Figma and build the front end myself, mostly in React and Supabase. I'm especially interested in fintech: making money tools easier for people my age.

🌐 **Portfolio:** [lucysylee.com](https://lucysylee.com)
🔎 **Open to:** Summer 2027 product design internships

### Projects

- **[Roomie Receipts](https://roomie-receipts.pages.dev/)** · [case study](https://lucysylee.com/work/roomie-receipts)
  A no-login bill-splitting app my roommates and I used for a year. In v2 I fixed a disappearing cent with integer-cent math, locked down data with Row Level Security, and raised Lighthouse accessibility from 88 to 100.
  `React` `Vite` `Supabase` `Cloudflare Pages`

- **UofT Pathfinder** *(in progress)*
  A node-based course planner that makes prerequisites readable. I lead UI/UX and the frontend in a 5-person AKCSE team.
  `Figma` `Supabase Auth`

- **[AKCSE UofT Website](https://akcseuoft.ca)**
  The chapter's website, with events synced automatically from Google Calendar.
  `Next.js` `Tailwind CSS` `Supabase` `Google Calendar API`
